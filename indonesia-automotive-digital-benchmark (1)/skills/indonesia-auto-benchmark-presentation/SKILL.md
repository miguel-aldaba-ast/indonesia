# Purpose

Transform a completed automotive digital benchmark into an executive PowerPoint presentation.

Do not redo the full research unless evidence is missing. When evidence is missing, verify only the affected claim or capability and label any unresolved gap.

Use as input:
- capability inventory
- brand × capability matrix
- maturity scores
- evidence URLs
- key differences
- screenshot list or uploaded screenshots
- user-provided PPT template if available

# Default output

Create a 16:9 executive presentation.

Default title:
Indonesia Automotive Digital Benchmark

Default subtitle:
Digital capabilities across automotive brand websites

# Required structure

Slide 1 — Cover
Title, subtitle, brands analysed, date.

Slide 2 — Executive summary
4–6 specific findings. No generic digital transformation language.

Slide 3 — Scope and methodology
Brands, official websites, research method, scoring system.

Slide 4 — Capability landscape
Main heatmap. Brands as columns. Capabilities as rows. Visible gridlines. Maturity score 0–4.

Slide 5 — Market maturity view
Group capabilities into:
- Table stakes
- Developing
- Advanced
- Distinctive

Slide 6 onwards — Capability deep dives
Create only the most relevant deep dives. Potential sections:
- Discovery and comparison
- Configuration
- Pricing and finance
- Conversion and lead generation
- Dealer and inventory
- Aftersales
- Connected vehicle
- Electrification
- AI / assistance
- Personalisation

Each deep dive must include:
- conclusion headline
- short comparison
- evidence screenshots where available
- maturity labels
- source footer

Brand snapshots — optional
Only include if they add value. Do not create one slide per brand by default.

Final slide — Key patterns and white spaces
Summarise what is common, what is emerging, what is advanced and where the main gaps are.

Appendix
Include full matrix, evidence log and source list.

# Screenshot rules

Screenshots are evidence, not decoration.

Use screenshots only when they demonstrate the specific capability discussed.

Do not fabricate screenshots.

Do not use generated images as website evidence.

If screenshots are missing, create a slide-ready screenshot capture list with:
- brand
- capability
- URL
- required page state
- reason for screenshot

# Design rules

Use the Astara template if provided.

Prioritise:
- large screenshots
- clean matrices
- short headlines
- readable tables
- clear hierarchy
- evidence footers

Avoid:
- generic consulting graphics
- excessive icons
- dense text
- tiny tables
- unnecessary cards
- decorative AI imagery
- fake laptop mockups unless requested

# Writing style

Use concise analytical language.

Avoid:
- seamless
- game-changing
- revolutionary
- unlocking
- redefining
- robust ecosystem
- digital transformation journey

Prefer:
"The configurator connects variant selection with finance simulation."

Instead of:
"The brand delivers a seamless end-to-end digital journey."

# Quality checks before finalising

Check:
- every slide has one clear idea
- all major claims come from the evidence matrix
- URLs are retained in source footers or appendix
- scores are consistent with the 0–4 maturity system
- screenshots match the claims
- matrix gridlines are visible
- text is readable
- no invented functionality
- no invented screenshots
